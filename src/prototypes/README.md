# prototypes/

Copias editables donde el equipo aplica mejoras de CSS/HTML/TS para mostrarle a Producto
antes de llevarlas al repo real.

Reglas:

- Se crean copiando desde `../mirrors/` (nunca se auto-sincronizan desde los repos reales).
- Editar libremente: es el lugar pensado para experimentar.
- Cuando Producto aprueba un cambio, se porta manualmente al repo real correspondiente
  (Fee/Menu/Header/Auth) como una tarea de desarrollo normal — no hay sync automático de vuelta.
